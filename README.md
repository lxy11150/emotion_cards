# 情绪卡牌小冒险

一款面向学龄前儿童的情绪理解卡牌小游戏。玩家扮演“小小心灵勇士”，在情绪小精灵的陪伴下，用卡牌面对 5 个负面情绪化身和最终的综合情绪 Boss，通过战斗认识情绪、理解情绪影响，并学习合适的应对方式。

## 游戏目标

游戏希望让儿童在轻量、卡通、可互动的战斗中理解：

- 不同情绪会带来不同的身体和行为影响。
- 负面情绪不是“坏东西”，而是需要被看见、理解和照顾。
- 每种情绪都可以用合适的方法慢慢处理。
- 快乐、冷静、接纳、勇气、宽容、镇定等能力可以帮助自己恢复状态。

## 核心玩法

玩家和怪物轮流行动。玩家每回合抽满 6 张手牌，并拥有 3 点情绪能量。每张普通牌消耗 1 点能量，“快乐”消耗 2 点能量。

玩家可以使用：

- 攻击牌：造成 6 点伤害。
- 防御牌：获得 5 点护甲，玩家护甲只持续当前回合。
- 能力牌：获得快乐或清除对应负面情绪。

怪物每回合会显示下一步意图，包括攻击、防御、施加负面情绪。怪物护盾也只持续一回合，不会跨回合累加。

击败一个怪物后，玩家会回到情绪王国地图。进入下一关挑战时，手牌、抽牌堆、弃牌堆都会像新游戏一样重置：弃牌堆清空，抽牌堆重新洗牌，再抽满 6 张手牌。

## 关卡与怪物

游戏共有 6 关：

1. 泪滴怪：悲伤化身
2. 火火怪：愤怒化身
3. 影子怪：恐惧化身
4. 跳跳怪：惊讶化身
5. 皱皱怪：厌恶化身
6. 乱乱大王：综合情绪 Boss

前 5 个普通怪物只能施加自己的负面情绪。Boss 会施加所有负面情绪，并在玩家清除所有负面情绪后隔两个回合再次施加。

## 情绪效果

| 情绪 | 游戏效果 | 对应能力牌 | 引导含义 |
| --- | --- | --- | --- |
| 悲伤 | 攻击力减半 | 接纳 | 难过时可以慢慢来，允许自己有情绪 |
| 愤怒 | 受到伤害增加 50% | 冷静 | 生气时先停一停，呼吸后再表达 |
| 恐惧 | 防御卡获得的护甲减半 | 勇气 | 害怕时可以找信任的大人帮忙 |
| 惊讶 | 完全防住攻击则转为快乐，否则转为恐惧 | 镇定 | 突然发生事情时，先看一看、想一想 |
| 厌恶 | 出牌有 50% 概率无效 | 宽容 | 可以表达不喜欢，也试着听听别人想法 |

“快乐”不是清除负面情绪的能力牌，而是一种增益状态。快乐状态下，攻击和防御数值翻倍；一旦怪物施加新的负面情绪，快乐状态会消失。

## 新手引导

普通怪物第一次施加某个负面情绪时，游戏会进入强引导：

- 情绪小精灵会说明这个情绪在生活中的影响。
- 对应能力牌会被放入手牌。
- 该能力牌会闪光，并有小手指向。
- 在使用这张能力牌前，其他牌和“结束回合”按钮都会被锁定。

普通怪战斗中，如果玩家身上有某个负面情绪，对应能力牌抽到后会保留在手牌中，直到使用。Boss 战不启用该保留规则。

## 重开与存档

- 玩家初始 HP 为 50。
- 进入新关卡时，会记录当前 HP 作为“本关开始血量”。
- 点击“重开本关”会重置当前怪物、牌堆、状态，并把玩家 HP 恢复到本关开始血量。
- 放弃游戏会从第一关重新开始。
- 游戏进度会同时写入浏览器 localStorage 和本地文件 `data/save.json`。

## 页面内容

游戏包含：

- 开始界面
- 初次新游戏剧情
- 情绪王国地图
- 怪物介绍页
- 新游戏 / 继续游戏
- 规则页
- 情绪图鉴
- 战斗界面
- 抽牌堆与弃牌堆查看
- 随时查看规则 / 图鉴
- 保存并退出
- 情绪小精灵文字提示
- 中文语音朗读提示
- 拼音 ruby 标注
- 卡通 CSS 角色、怪物、地图与剧情动态效果

## 交互设备

游戏以浏览器为主要运行环境，适合以下设备使用：

- 桌面电脑或笔记本：使用鼠标点击按钮、卡牌、抽牌堆和弃牌堆。
- 平板电脑：使用触摸点击卡牌和界面按钮，更适合儿童直接操作。
- 大屏互动设备：可用于亲子共玩、课堂演示或教师带领活动。

由于目标用户是学龄前儿童，交互以“点击”为主，不依赖复杂键盘操作。页面采用响应式布局，能在较宽桌面屏和较窄移动屏上自动调整卡牌排列。游戏包含语音朗读提示，建议设备开启扬声器或耳机，以便儿童能同时通过听觉和视觉理解情绪引导。

## 界面设计

界面采用卡通、明亮、低压力的视觉风格，避免过于紧张或写实的战斗表现。整体设计重点是让儿童能快速看懂“我是谁、怪物是谁、下一步要做什么”。

- 开始界面：展示游戏名称、小小心灵勇士和主要入口，包括新游戏、继续游戏、规则和情绪图鉴。
- 剧情界面：第一次新游戏会讲述情绪王国被乱乱大王侵袭，小朋友玩家成为小小心灵勇士的背景故事，可选择下一话或跳过剧情。
- 地图界面：展示情绪王国路线图，每个节点代表一个情绪怪物区域；当前可挑战节点会发光，已通过区域会显示为恢复状态。
- 怪物介绍页：挑战前展示怪物插画、所在区域、情绪影响和简短故事，再由玩家点击开始挑战。
- 战斗区域：左右分布玩家和怪物，玩家可以看到自己的 HP、护甲、快乐状态和负面情绪；怪物区域显示怪物形象、HP、护盾和下一回合意图。
- 情绪小精灵提示区：位于战斗区下方，用短句说明当前情绪、现实生活中的表现，以及应使用的能力卡。
- 手牌区域：展示本回合可用卡牌、情绪能量、抽牌堆、弃牌堆和结束回合按钮。
- 情绪图鉴：以卡片形式介绍每种情绪的游戏效果、对应能力牌和现实应对方式。

卡牌和按钮都使用较大的点击区域，文字配有拼音标注，降低儿童阅读门槛。首次遇到负面情绪时，对应能力牌会闪光，并出现小手指向，让儿童不需要阅读大量文字也能理解下一步操作。

## 交互过程

一次完整游戏流程如下：

1. 玩家进入开始界面，可以选择“新游戏”开始，也可以在已有存档时选择“继续游戏”。
2. 第一次新游戏会进入剧情界面，玩家可以点击“下一话”阅读故事，也可以跳过剧情。
3. 剧情结束后进入情绪王国地图，玩家点击当前发光的怪物区域。
4. 怪物介绍页会展示该区域的故事、怪物特点和挑战按钮。
5. 玩家进入战斗界面后，先观察怪物的“下一步”意图，判断怪物准备攻击、防御还是施加情绪。
6. 玩家查看手牌，根据当前能量选择攻击、防御、快乐或能力牌。
7. 玩家出牌后，攻击会扣除怪物 HP，防御会增加玩家护甲，能力牌会提供快乐或清除对应负面情绪。
8. 玩家点击“结束回合”，怪物按意图行动，可能攻击、获得护盾、施加负面情绪，或在 Boss 战中发动情绪风暴。
9. 回合结束后，玩家护甲清空，怪物护盾也不会跨多个回合累加；手牌进入弃牌堆，系统重新抽满 6 张牌。
10. 普通怪首次施加负面情绪时，游戏会锁定引导流程，只允许玩家使用对应能力牌，帮助儿童建立“情绪-影响-应对方式”的对应关系。
11. 击败当前怪物后回到地图，下一条路线会亮起。开始下一关时，玩家保留剩余 HP，但牌堆完全重置。
12. 如果点击“重开本关”，当前怪物、牌堆和状态会重置，玩家 HP 回到本关开始时的血量。
13. 玩家可以在游戏中随时查看规则、查看图鉴，或点击“保存并退出”回到开始界面。
14. 击败最终 Boss 后完成通关。

## 技术栈

- React
- Vite
- JavaScript
- CSS
- Express 本地服务

Express 服务用于提供前端页面，并通过 `/api/save` 接口把游戏进度保存到本地文件。

## 本地运行

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

打开浏览器访问：

```text
http://localhost:5173
```

构建生产版本：

```bash
npm run build
```

预览生产构建：

```bash
npm run preview
```

## 适用方向

这个原型适合作为儿童情绪教育小游戏的基础版本，后续可以继续扩展：

- 更丰富的角色素材和怪物动画
- 更细致的语音包或真人配音
- 更多生活情境小剧情
- 家长/教师说明模式
- 难度调节与关卡平衡
- 通关反馈与情绪学习报告
